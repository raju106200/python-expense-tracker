# Python Expense Tracker

## Description
A simple Python mini project to manage daily expenses. It allows users to add expenses, view saved expenses, and calculate total expenses.

## Features
- Add new expenses
- View all expenses
- Calculate total expenses
- Save data in a text file
- Menu-driven program

## Concepts Used
- Python Functions
- While Loop
- If-Else Statements
- File Handling
- Exception Handling

## File
`expense_tracker.py`

## Data Storage
Expenses are saved in `expenses.txt`.

## How to Run
```bash
python expense_tracker.py
```
